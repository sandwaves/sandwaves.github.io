# Syntax templates

Copy-paste snippets for the Markdown that the Chirpy theme supports, one file per section of
<https://chirpy.cotes.page/posts/text-and-typography/>.

Jekyll ignores folders that start with `_` unless they are configured as collections, so nothing in
this folder is built or published.

| File | Section |
| --- | --- |
| `00-front-matter.md` | Post front matter, including the flags that turn on math and mermaid |
| `01-headings.md` | Headings |
| `02-paragraph.md` | Paragraph |
| `03-lists.md` | Ordered, unordered, to-do and description lists |
| `04-block-quote.md` | Block quote |
| `05-prompts.md` | Tip, info, warning and danger callouts |
| `06-tables.md` | Tables and column alignment |
| `07-links.md` | Links |
| `08-footnotes.md` | Footnotes and where their text goes |
| `09-inline-code.md` | Inline code |
| `10-filepath.md` | Filepath highlight |
| `11-code-blocks.md` | Code blocks: plain, with a language, with a filename |
| `12-mathematics.md` | MathJax equations (needs `math: true`) |
| `13-mermaid.md` | Mermaid diagrams (needs `mermaid: true`) |
| `14-images.md` | Images: caption, alignment, float, dark/light, shadow |
| `15-video.md` | Embedded video |
| `16-glossary-tooltip.md` | Glossary term tooltips (jekyll-glossary_tooltip plugin) |
