title: VS Code shortcuts
description: Default VS Code keyboard shortcuts on Windows, grouped by task.

Default keymap on Windows. Search or rebind any of these in {% kbd Ctrl+K Ctrl+S %}.

## General

| Action | Keys |
| --- | --- |
| Command Palette | {% kbd Ctrl+Shift+P %} or {% kbd F1 %} |
| Quick Open a file | {% kbd Ctrl+P %} |
| Settings | {% kbd Ctrl+, %} |
| Keyboard shortcuts | {% kbd Ctrl+K Ctrl+S %} |
| Toggle terminal | {% kbd Ctrl+` %} |
| New terminal | {% kbd Ctrl+Shift+` %} |

## Editing lines

| Action | Keys |
| --- | --- |
| Move line up / down | {% kbd Alt+Up %} / {% kbd Alt+Down %} |
| Copy line up / down | {% kbd Shift+Alt+Up %} / {% kbd Shift+Alt+Down %} |
| Delete line | {% kbd Ctrl+Shift+K %} |
| Insert line below / above | {% kbd Ctrl+Enter %} / {% kbd Ctrl+Shift+Enter %} |
| Indent / outdent line | {% kbd Ctrl+] %} / {% kbd Ctrl+[ %} |
| Toggle line comment | {% kbd Ctrl+/ %} |
| Toggle block comment | {% kbd Shift+Alt+A %} |
| Format document | {% kbd Shift+Alt+F %} |
| Toggle word wrap | {% kbd Alt+Z %} |

## Multi-cursor and selection

| Action | Keys |
| --- | --- |
| Add next match to selection | {% kbd Ctrl+D %} |
| Select all matches | {% kbd Ctrl+Shift+L %} |
| Add cursor above / below | {% kbd Ctrl+Alt+Up %} / {% kbd Ctrl+Alt+Down %} |
| Cursor at end of each selected line | {% kbd Shift+Alt+I %} |
| Select current line | {% kbd Ctrl+L %} |
| Expand / shrink selection | {% kbd Shift+Alt+Right %} / {% kbd Shift+Alt+Left %} |

## Navigation

| Action | Keys |
| --- | --- |

| Go to symbol in file | {% kbd Ctrl+Shift+O %} |

| Show references | {% kbd Shift+F12 %} |
| Go back / forward | {% kbd Alt+Left %} / {% kbd Alt+Right %} |
| Matching bracket | {% kbd Ctrl+Shift+\ %} |
